# ADR-0001：EIS Spec v1.0 冻结

- **状态**：Accepted
- **日期**：2026-10-08
- **决策者**：核心维护者

## 1. 变更原因

EIS 规范经草案阶段（六份契约的结构、语义、验证方式）后达到可冻结标准：
每条契约均可实例化（本仓库为其工件）、可验证（含测试用例与验证工具）、可演进（含兼容性规则与迁移路径）。
冻结为用户提供稳定基线。

## 2. 影响范围

- 数据契约元结构、操作契约元结构、时间契约语义、授权契约接口、审计契约元结构、演进契约元规则（详见 `../core-freeze.md`）。
- 未冻结：领域扩展、应用案例、工具实现。

## 3. 兼容性分析

- 级别：初始版本，无既有消费者，判定为 MINOR 起点 `1.0.0`（首次冻结视为初始基线）。
- 破坏点：无（相对草案的措辞收敛不构成契约变更）。

## 4. 迁移方案

- 不适用（初始版本）。后续任何 MAJOR 变更必须提供 `06-evolution-contract/` 模板下的迁移与回滚脚本。

## 5. 回滚方案

- 回滚 = 回退本仓库至冻结前提交；不涉及生产数据。

## 6. 可执行工件

| 工件 | 路径 | 说明 |
|------|------|------|
| 核心 DDL | `01-data-contract/core.ddl` | 域 + 模板表 |
| 契约 Schema | `01-data-contract/*.schema.json` | 对象/事件/命令/视图/时间 |
| 操作契约 | `02-operation-contract/*.yaml` | 命令/查询/事件/错误码 |
| 时间契约 | `03-time-contract/*` | 规则/DDL/模板/API |
| 授权契约 | `04-authz-contract/*` | 主体/角色/绑定/代理/解析/SoD |
| 审计契约 | `05-audit-contract/*` | Schema/DDL/哈希链规范/verify.tool |
| 演进契约 | `06-evolution-contract/*` | 兼容规则/迁移/回滚模板 |
| 验收标准 | `acceptance.yaml` | 核心项 + 试点项 |

## 7. 验收用例

- 全部核心验收项（`acceptance.yaml` 的 `acceptance.core`）。
- 试点验收项在 `cases/procurement` 完成后执行。
